# 2.Consultas mongo

## 1. Estrutura de uma consulta

No `mongosh`, `find()` recebe um **filtro** e, opcionalmente, uma **projeção** dos campos que devem aparecer no resultado. Depois, é possível aplicar modificadores ao cursor, como `sort()` e `limit()`.

```javascript
db.colecao.find(
  { campo: valor },       // filtro: quais documentos encontrar
  { campo: 1, _id: 0 }   // projeção: quais campos retornar
).sort({ campo: 1 }).limit(10)
```

Em `sort()`, `1` significa ordem crescente e `-1`, decrescente. Na projeção, `1` inclui um campo e `0` o exclui. O campo `_id` aparece por padrão, mesmo quando os demais campos são selecionados; use `_id: 0` para ocultá-lo.

Exemplo da aula, com a coleção `pedidos`:

```javascript
db.pedidos.find(
  { "itens.qtde": { $gte: 1 } },
  { id_cliente: 1, "itens.descricao": 1 }
).sort({ _id: -1 })
```

Essa consulta procura pedidos com ao menos um item cuja quantidade seja maior ou igual a 1, retorna os campos indicados e ordena os resultados pelo `_id` decrescente.

### Documento usado nos exemplos

Os exemplos seguintes consideram a coleção `livros` da base `biblioteca`. Um documento pode ter subdocumentos (`autor`, `editora`) e arrays (`keywords`, `comentarios`):

```javascript
{
  _id: 1,
  titulo: "Introdução ao MongoDB",
  autor: { nome: "Lucas Ferreira", ano_nascimento: 1990 },
  ano_publicacao: 2020,
  genero: "Tecnologia",
  keywords: ["MongoDB", "NoSQL", "Banco de Dados"],
  editora: { nome: "Editora Tech", pais: "Brasil" },
  disponibilidade: true,
  comentarios: [
    { usuario: "ana123", classificacao: 5, conteudo: "Excelente livro!" },
    { usuario: "joao_silva", classificacao: 3, conteudo: "Esperava mais." }
  ],
  paginas: 150
}
```

Os exemplos de consulta são independentes: **esse único documento ilustrativo não satisfaz todos os filtros**.

## 2. Filtros e operadores de comparação

| Operador | Significado | Exemplo de condição |
| --- | --- | --- |
| `$gt` | Maior que | `{ paginas: { $gt: 100 } }` |
| `$gte` | Maior ou igual | `{ paginas: { $gte: 180 } }` |
| `$lt` | Menor que | `{ paginas: { $lt: 200 } }` |
| `$lte` | Menor ou igual | `{ paginas: { $lte: 150 } }` |
| `$ne` | Diferente de | `{ genero: { $ne: "Tecnologia" } }` |

```javascript
db.livros.find({ paginas: { $gte: 180 } })
```

Para datas armazenadas como `Date`, compare com valores do mesmo tipo:

```javascript
db.pedidos.find({ data: { $gt: ISODate("2020-08-01") } })
db.pedidos.find({
  data: {
    $gte: ISODate("2020-08-01"),
    $lte: ISODate("2024-12-31")
  }
})
```

`$ne` também pode selecionar documentos sem o campo consultado. Se a intenção for exigir que o campo exista, combine com `$exists: true`.

### Combinação de condições

Condições em campos diferentes dentro do mesmo filtro formam um **E** implícito. `$and` deixa esse agrupamento explícito; `$or` aceita qualquer uma das condições; `$nor` exige que nenhuma delas seja satisfeita.

```javascript
db.livros.find({
  $and: [
    { paginas: { $lte: 150 } },
    { ano_publicacao: { $gt: 2020 } },
    { "autor.ano_nascimento": { $gt: 1990 } }
  ]
})
```

Para buscar livros de dois gêneros, publicados **depois** de 2015:

```javascript
db.livros.find({
  $and: [
    { $or: [{ genero: "Tecnologia" }, { genero: "Ficção Científica" }] },
    { ano_publicacao: { $gt: 2015 } }
  ]
})
```

`$gt: 2015` exclui o próprio ano de 2015; para incluí-lo, use `$gte: 2015`.

### Vários valores e campos ausentes

```javascript
db.livros.find({ genero: { $in: ["Tecnologia", "Ficção Científica"] } })
db.livros.find({ disponibilidade: { $exists: false } })
```

`$in` seleciona qualquer valor da lista. `$exists: false` seleciona documentos **sem** o campo `disponibilidade`; não significa `disponibilidade: false`.

## 3. Projeção e subdocumentos

A projeção limita os campos retornados. Para acessar um campo dentro de um subdocumento, use a **notação com ponto** e coloque o caminho entre aspas:

```javascript
db.livros.find(
  { genero: "Tecnologia" },
  { titulo: 1, paginas: 1, _id: 0 }
)

db.livros.find({ "editora.nome": "Editora Tech" })

db.livros.find(
  { ano_publicacao: { $gte: 2018 } },
  { titulo: 1, "editora.nome": 1, _id: 0 }
)
```

No primeiro exemplo, `"Tecnologia"` é uma string e precisa de aspas. No último, a projeção retorna apenas o título e o nome da editora.

## 4. Consultas em arrays

Ao comparar um array com um valor simples, o MongoDB encontra documentos cujo array **contém** esse valor:

```javascript
db.livros.find({ keywords: "MongoDB" })
```

Use `$all` quando **todos** os valores indicados devem estar presentes; `$in` basta quando **qualquer um** serve:

```javascript
db.livros.find({ keywords: { $all: ["Banco de Dados", "NoSQL"] } })
db.livros.find({ keywords: { $in: ["Python", "SQL"] } })
```

O operador de consulta `$size` seleciona arrays com **exatamente** a quantidade indicada:

```javascript
db.livros.find({ keywords: { $size: 3 } })
```

Para **calcular** o tamanho do array e mostrá-lo como campo no resultado, usa-se a expressão de agregação `$size` na projeção:

```javascript
db.livros.find(
  {},
  { titulo: 1, paginas: 1, numeroComentarios: { $size: "$comentarios" }, _id: 0 }
)
```

Essa projeção pressupõe que `comentarios` seja um array nos documentos consultados. Já `$slice` na projeção limita os elementos retornados de um array:

```javascript
db.livros.find({}, { comentarios: { $slice: 2 } })
```

O exemplo retorna os dois primeiros comentários de cada livro; `_id` continua presente, pois não foi excluído.

## 5. Comparar campos do mesmo documento com `$expr`

Em um filtro comum, `"$outroCampo"` não é interpretado como referência a campo. `$expr` permite usar expressões e comparar os valores de dois campos do **mesmo documento**:

```javascript
db.livros.find({
  $expr: { $eq: ["$ano_publicacao", "$autor.ano_nascimento"] }
})
```

O `$` antes do nome indica uma referência ao valor do campo; `$eq` testa igualdade.

## 6. Agregações

`aggregate()` recebe um **pipeline**: cada etapa recebe os documentos produzidos pela etapa anterior. `$match` filtra, `$group` agrupa e calcula, e `$sort` ordena a saída.

```javascript
db.livros.aggregate([
  { $match: { genero: "Tecnologia" } },
  { $group: { _id: "$genero", totalPaginas: { $sum: "$paginas" } } },
  { $sort: { _id: 1 } }
])
```

No `$group`, `_id` define a chave do grupo. Aqui, cada gênero gera um resultado e `$sum` soma as páginas dos livros desse gênero. Para a média:

```javascript
db.livros.aggregate([
  { $group: { _id: "$genero", mediaPaginas: { $avg: "$paginas" } } }
])
```

Para **contar documentos por gênero**, some `1` para cada livro:

```javascript
db.livros.aggregate([
  { $group: { _id: "$genero", totalLivros: { $sum: 1 } } },
  { $sort: { _id: 1 } }
])
```

### `$unwind`: um documento por elemento do array

`$unwind` desdobra um array. Se um livro tiver três comentários, a etapa produz três documentos temporários, cada um com um comentário. Isso permite calcular uma estatística por comentário e depois voltar a agrupar por livro:

```javascript
db.livros.aggregate([
  { $unwind: "$comentarios" },
  {
    $group: {
      _id: "$_id",
      titulo: { $first: "$titulo" },
      classificacaoMedia: { $avg: "$comentarios.classificacao" }
    }
  },
  { $sort: { _id: 1 } }
])
```

Com classificações `5` e `3` do documento ilustrativo, a média é `4`. Por padrão, documentos com array vazio ou ausente não passam pela etapa `$unwind`.

O campo `titulo` precisa de um acumulador no `$group`. `$first` pega o valor do primeiro documento do grupo; `$last`, o último. Como todas as linhas geradas pelo mesmo livro têm o mesmo título, ambos servem nesse caso. Se os valores puderem variar, use `$sort` **antes** do `$group` para definir o que significa “primeiro” ou “último”.

### Acumuladores importantes

| Acumulador | Uso dentro de `$group` |
| --- | --- |
| `$sum: "$campo"` | Soma valores numéricos do campo |
| `$sum: 1` | Conta documentos do grupo |
| `$avg: "$campo"` | Calcula a média |
| `$min: "$campo"` | Obtém o menor valor |
| `$max: "$campo"` | Obtém o maior valor |
| `$first: "$campo"` | Obtém o primeiro valor na ordem de entrada |
| `$last: "$campo"` | Obtém o último valor na ordem de entrada |
| `$push: "$campo"` | Cria um array com todos os valores, inclusive repetidos |
| `$addToSet: "$campo"` | Cria um array de valores únicos; sua ordem não é garantida |

Aplicando outros acumuladores às classificações dos comentários:

```javascript
db.livros.aggregate([
  { $unwind: "$comentarios" },
  {
    $group: {
      _id: "$_id",
      titulo: { $first: "$titulo" },
      menorClassificacao: { $min: "$comentarios.classificacao" },
      maiorClassificacao: { $max: "$comentarios.classificacao" },
      somaClassificacoes: { $sum: "$comentarios.classificacao" },
      todasClassificacoes: { $push: "$comentarios.classificacao" },
      classificacoesUnicas: { $addToSet: "$comentarios.classificacao" }
    }
  }
])
```

Os operadores válidos são `$max` e `$sum`; termos como “máximo” e “soma” descrevem a operação, mas não são nomes de operadores do MongoDB.

## 7. Contar documentos

`countDocuments(filtro)` conta documentos que satisfazem um filtro, sem retornar esses documentos:

```javascript
db.livros.countDocuments({ paginas: { $gt: 100 } })
db.livros.countDocuments({ keywords: { $size: 3 } })
db.livros.countDocuments({ keywords: "Python" })
db.livros.countDocuments({ keywords: { $in: ["Python", "SQL"] } })
db.livros.countDocuments({ keywords: { $all: ["Python", "SQL"] } })
```

`$size: 3` exige **exatamente três** palavras-chave. Para **pelo menos três**, compare o tamanho calculado com `$expr`:

```javascript
db.livros.countDocuments({
  $expr: { $gte: [{ $size: "$keywords" }, 3] }
})
```

Esse último exemplo pressupõe que `keywords` seja um array. A aula também usa um ano de nascimento fixo para ilustrar uma faixa etária; esse número deixa de representar “menos de 30 anos” com o passar do tempo. Para uma idade real, é necessário calcular a partir da data atual e de uma data de nascimento completa.

## 8. Exercícios da aula

Considere as coleções `bandas`, `locais` e `shows`. Estes são exemplos dos documentos apresentados:

```javascript

  _id: "Coldplay",

  integrantes: [
    { nome: "Chris Martin", instrumentos: ["Vocal", "Piano", "Guitarra"] },
    { nome: "Jonny Buckland", instrumentos: ["Guitarra"] },
    { nome: "Guy Berryman", instrumentos: ["Baixo"] },
    { nome: "Will Champion", instrumentos: ["Bateria"] }
  ]

// locais
{
  _id: "Maracanã",
  logradouro: "Av. Presidente Castelo Branco",

  cidade: "Rio de Janeiro",
  estado: "RJ",
  valor_aluguel: 500000,
  capacidade_publico: 78838
}

// shows: a data do exemplo é uma string no formato AAAA-MM-DD
{
  _id: { banda: "Coldplay", local: "Maracanã", data: "2024-12-15" },
  valor_ingresso: 350,
  total_ingressos: 70000,
  detalhes_banda: {
    ano_criacao: 1996,

      { nome: "Chris Martin", instrumentos: ["Vocal", "Piano", "Guitarra"] },
      { nome: "Jonny Buckland", instrumentos: ["Guitarra"] },

      { nome: "Will Champion", instrumentos: ["Bateria"] }

    cidade: "Rio de Janeiro",
    estado: "RJ",
    valor_aluguel: 500000,
    capacidade_publico: 78838
  }

```

Elabore comandos MongoDB para:

1. Listar todas as bandas cadastradas.
2. Listar somente os nomes de todas as bandas.
3. Buscar todas as informações sobre a banda “U2”.
4. Exibir o nome e o ano de criação das bandas criadas após 1990.

6. Listar locais com capacidade de público superior a 60.000 pessoas.
7. Listar locais disponíveis na cidade de São Paulo.

9. Listar bandas e datas dos shows no “Allianz Parque”.
10. Listar shows realizados em 07/12/2024.
11. Buscar shows em uma cidade específica.
12. Buscar shows com ingresso abaixo de R$ 500,00.
13. Listar bandas que já tocaram no Morumbi.
14. Listar shows realizados em 2024.
15. Listar shows da banda “Coldplay” realizados em 2024.
16. Contar o total de shows realizados em um local específico.
17. Listar shows realizados no estado de São Paulo (`SP`).
18. Listar os ingressos disponíveis para o show da banda “Iron Maiden”.
19. Obter o ano de criação da banda mais antiga.
20. Obter o local com maior capacidade de público.
21. Calcular a capacidade média de público dos locais.
22. Somar os ingressos disponibilizados em todos os shows.
23. Calcular a arrecadação total, supondo que todos os ingressos foram vendidos.
24. Contar os shows por banda.
25. Contar os shows por local.
26. Calcular o valor médio dos ingressos de todos os shows.
27. Listar o show com o maior número de ingressos disponíveis.
28. Calcular o valor médio do aluguel dos locais.

> [!important] Atenção ao modelo dos exercícios
> No exemplo, `shows._id.data` é **string**, não `Date`; a consulta deve respeitar o tipo armazenado. `locais` não possui um campo de disponibilidade. `total_ingressos` informa o total disponibilizado, mas não quantos foram vendidos. Portanto, os itens 7, 18 e 27 precisam de uma definição adicional para “disponível” antes de terem uma resposta exata sobre disponibilidade atual.

## 9. Resumo dos comandos

| Objetivo | Comando ou forma geral |
| --- | --- |
| Consultar documentos | `db.colecao.find({ filtro }, { projecao })` |
| Ordenar e limitar | `.sort({ campo: 1 ou -1 }).limit(n)` |
| Comparar valores | `$gt`, `$gte`, `$lt`, `$lte`, `$ne`, `$eq` |
| Combinar filtros | `$and`, `$or`, `$nor` |
| Aceitar um entre vários valores | `{ campo: { $in: [a, b] } }` |
| Exigir campo presente ou ausente | `{ campo: { $exists: true ou false } }` |
| Acessar subdocumento | `{ "subdocumento.campo": valor }` |
| Exigir todos os valores de um array | `{ array: { $all: [a, b] } }` |
| Exigir tamanho exato de array | `{ array: { $size: n } }` |
| Retornar só parte de um array | `{ array: { $slice: n } }` na projeção |
| Comparar campos ou expressões | `{ $expr: { $eq: ["$campo1", "$campo2"] } }` |
| Contar documentos | `db.colecao.countDocuments({ filtro })` |
| Processar em etapas | `db.colecao.aggregate([{ $match: ... }, { $group: ... }])` |
| Desdobrar array | `{ $unwind: "$array" }` |
| Agrupar documentos | `{ $group: { _id: "$campo", resultado: { $sum: 1 } } }` |
| Calcular por grupo | `$sum`, `$avg`, `$min`, `$max`, `$first`, `$last` |
| Reunir valores por grupo | `$push` (todos) ou `$addToSet` (únicos) |

**Lembrete:** no filtro, `$size: n` testa o tamanho exato do array; na projeção, `{ $size: "$array" }` calcula e mostra seu tamanho. Para contar grupos, use `$sum: 1`; para somar valores, use `$sum: "$campo"`.
